# astro_app

Vedic astrology mobile app: Expo (React Native) client, Fastify API on Cloud Run, Firestore, Firebase Auth. Charts, dasha and daily predictions come from AstrologyAPI.com.

- **Status, test evidence, risks:** `docs/STATUS.md`
- **Develop, test, operate, deploy:** `docs/handover.md`
- **Cloud setup (not run yet; needs your accounts):** `infra/gcp/README.md`
- **Design:** `docs/requirements.md`, `docs/architecture.md`, `docs/data-model.md`, `docs/backlog.md`

Quick start: `npm ci`, copy `.env.example` to `.env`, then `npm run check`.
